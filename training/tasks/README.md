# Student tasks

This directory contains student-visible task baselines only. Phase 3 intentionally provides no pilot task; TRN-001, TRN-003, and TRN-012 are Phase 4 work.

Every future `TRN-###` directory must contain `manifest.yaml`, `student-ticket.md`, `reproduce.ps1`, `visible-tests/`, and `expected-evidence.md`. Mentor notes, solution patches, hidden tests, hints, and reference diffs are forbidden here and must live in a separately access-controlled mentor repository.

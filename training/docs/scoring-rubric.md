# Task scoring rubric

Every task is scored out of 100. Passing automated tests is necessary but is not sufficient for an acceptable engineering solution.

| Area | Points |
|---|---:|
| Root-cause understanding and evidence | 20 |
| Correctness | 20 |
| Backward compatibility | 15 |
| Test quality | 15 |
| HTTP, database, and integration verification | 10 |
| Minimality and maintainability | 10 |
| Edge-case handling | 5 |
| PR and engineering communication | 5 |

Mentors record both the score and the evidence supporting each category. Hidden tests may detect missed behavior, but they never replace review of architecture, compatibility, scope, and verification quality.
